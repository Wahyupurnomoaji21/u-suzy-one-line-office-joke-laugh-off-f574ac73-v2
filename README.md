## About

This repository holds an entry for the make.fun competition "One-Line Office Joke Laugh-Off" (slug `u-suzy-one-line-office-joke-laugh-off-f574ac73`). The program writes one original one-line office joke (101 characters) to `/output/entry.txt`, where an AI judge compares it head-to-head against other entries. The joke:

> I wrote 'per my last email' 40 times in one thread, so HR added passive aggression to my core skills.

## Run it

```sh
node main.ts
```

The program writes `entry.txt` into `$MAKEFUN_OUTPUT_DIR` (or an `output/` directory next to `main.ts` for local runs). It resolves every path from `import.meta.url`, so it runs from any working directory.
